##  Lesson Content

### Decentralization: The Key Innovation

Bitcoin's breakthrough isn't just digital moneyit's **decentralized** digital money. Before Bitcoin, all digital payment systems required a trusted third party (like a bank or PayPal). Bitcoin solved the "double-spend problem" without needing trust.

### What is a Blockchain?

A blockchain is a **distributed ledger**a database shared across thousands of computers worldwide:

- **Blocks** contain groups of transactions
- Each block links to the previous block via cryptography
- This creates an **immutable chain** of records
- Anyone can verify the entire history

### Nodes: The Backbone of Bitcoin

A **node** is a computer running Bitcoin software that:

1. **Stores** a complete copy of the blockchain
2. **Validates** all transactions and blocks
3. **Relays** information to other nodes
4. **Enforces** the consensus rules

There are over **50,000 Bitcoin nodes** worldwide. This makes Bitcoin:
- **Censorship-resistant** - No one can stop transactions
- **Trustless** - You verify, don't trust
- **Resilient** - No single point of failure

### Game Theory: Why Bitcoin Works

Bitcoin uses **economic incentives** to align behavior:

| Actor | Incentive | Result |
|-------|-----------|--------|
| Miners | Block rewards | Secure the network |
| Nodes | Protect their coins | Enforce rules |
| Users | Store value | Demand for BTC |
| Developers | Improve software | Better Bitcoin |

Everyone benefits by following the rules. Cheating is expensive and unprofitable.

##  Key Takeaways

1. **Decentralization is Bitcoin's key innovation** - no trusted third party needed
2. **Blockchain is a distributed ledger** - shared across thousands of computers
3. **Nodes validate and enforce rules** - over 50,000 worldwide
4. **Game theory aligns incentives** - everyone benefits by following rules
5. **Bitcoin is trustless** - verify, don't trust
