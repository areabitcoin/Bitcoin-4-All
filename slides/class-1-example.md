# What is Bitcoin?

- **Digital money** - exists only on the internet
- **Decentralized** - no bank or government controls it
- **Scarce** - only 21 million will ever exist
- **Global** - works anywhere, 24/7

---

# When was Bitcoin created?

- **October 31, 2008** - Whitepaper published
- **January 3, 2009** - First block mined (Genesis Block)
- **Creator**: Satoshi Nakamoto (anonymous)

> "A purely peer-to-peer version of electronic cash"

---

# Why was Bitcoin created?

## The 2008 Financial Crisis

- Banks were bailed out with taxpayer money
- People lost their homes and savings
- Trust in financial institutions collapsed

**Bitcoin was the response.**

---

# The Genesis Block Message

```
"The Times 03/Jan/2009 Chancellor on brink 
of second bailout for banks"
```

Satoshi embedded this newspaper headline in the first Bitcoin block.

---

# Key Properties

| Property | Description |
|----------|-------------|
| **Decentralized** | No central authority |
| **Transparent** | All transactions are public |
| **Immutable** | Cannot be changed or reversed |
| **Permissionless** | Anyone can use it |
| **Scarce** | Fixed supply of 21 million |
